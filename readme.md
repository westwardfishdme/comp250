# Finch's Collective Notes for Comp 250
This repository is the collection of notes and assignments for COMP250 
(*Research Writing: Open Source Tools and Techniques*)

## Navigation
The directory is broken up by weeks; starting at enum 0, and proceeds sequentially all the way up.
A collection of notes are written with a mix of `LaTeX` and `MarkDown`; More code intensive notes
are going to be written in markdown due to it's ease of use for inserting code blocks and segments
with proper syntax highlighting.

**General notes** are written in LaTeX. This is done for a mix of reasons; both to learn and practice
and because it's nice.
